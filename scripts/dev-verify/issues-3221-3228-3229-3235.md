## Disposition record

### 2026-09-18: evidence and design review

The linked `TatsuKo-Tsukimi/suijie` patch/material API requests returned HTTP 404.
Their contents and the reported Mac CPU percentages were not independently
verified. Local deterministic work counters and real WebGPU pixels are the
acceptance evidence; no local result is presented as an M5 CPU measurement.

| Candidate | Decision |
|:--|:--|
| Disable probes whenever the watcher appears healthy | Rejected: silent missed events have no reliable health signal. Bounded adaptive probing keeps the recovery path. |
| Cache enum-bearing components in a WeakMap | Rejected: enum constraints are field-local. Validating only the patch removes the snapshot without another cache. |
| Duplicate Scene roots/topology or remove one schedule | Rejected: structural validation plus existing relationship lists preserves both schedule boundaries and producer ownership. |
| Numeric conversion for every TypedArray input | Rejected: different element types retain the existing raw-byte contract; shared handles retain owner-managed reference accounting. Same-type `set` preserves overlapping views. |
| Streaming material searches | Accepted: preserve first-match ordering and absent-shadow semantics without entries/filter/map/Set temporaries. |

Regression tests cover unchanged and edited subtrees, reparenting, malformed
graph recovery, external GlobalTransform edits, query observation cursors,
fixed-array overlap/zero padding, slow probes, and actual transparent pixels.
The transparent test also observes the native pipeline depth-write flag, so a
producer silently dropping `false` cannot pass merely by drawing opaque pixels.

Focused validation passed: 184 package test files / 1375 tests before the query
shortcut; 113 ECS/Scene files / 1130 tests after it; 72 focused rendering tests;
three real browser material cases; full TypeScript build. Complete final-commit
CI remains authoritative for fleet acceptance and is linked from the PR.

### 2026-09-18: CI timing-case startup evidence

Run `35360390841` failed the existing GPU timing raster-suppression browser
case at its implicit 15-second timeout. The failure reproduced with both
headless Chrome and the CI headed Chrome path. Temporary phase instrumentation
measured 16.758 seconds through renderer initialization, then 0.148 seconds for
all three draws and observations, and 0.001 seconds for disposal. Instrumentation
was removed after diagnosis.

The positive timing case already allows 30 seconds for the same fresh-renderer
startup path. Apply that same local completion bound to its raster-suppression
case; retain all three frames, timing assertions, falsifiers, and benchmark
thresholds. This corrects an inconsistent startup allowance, not a throughput
improvement. Complete CI must pass again on the resulting commit.

### 2026-09-19: process fixture readiness

Both attempts of run `35364649884` killed the inherited-pipe fixture before it
wrote its descendant PID. The unchanged focused file and full 246-test lifecycle
command passed locally; adding a deliberate 500 ms descendant startup delay
reproduced the failure and exposed the adjacent ordinary-child test's permissive
PID parser. That parser could read the leader PID from a timeout diagnostic.

Use an explicit descendant marker and a two-second fixture deadline. Preserve
the original inherited-pipe cleanup budget of 1250 ms after the deadline and
100 ms TERM grace, and verify the detached descendant survives until explicit
test cleanup. Production process management, retries, and deadlines are unchanged.
The operating guide records the owning regression and full concurrent command.

### 2026-09-19: Bevy audio Smoke submission pressure

Run `35366703492` stopped during `audio-control` without a useful termination
cause. A real local Dawn replay passed but reached 14754856 KiB peak RSS at
100 frames; the 300-frame replay exceeded 30 GiB RSS during execution. The three
audio drivers bypass Host pacing and enqueue all draws synchronously. Waiting
for the real native queue after each draw reduced `audio-control` peak RSS to
2327344 KiB for the full 300 frames, with all original assertions passing.

Apply that same driver correction to `audio` and `play-sound-effect`, which
contain the identical unpaced loop. This is a Smoke execution repair; game
scenes and Engine rendering are unchanged. Do not classify the remote failure
as a proven OOM kill: its missing termination cause remains an evidence limit.
