## Numerical evidence

Run `node bench/accuracy.mjs` after `pnpm build`. Raw data: [accuracy.json](evidence/accuracy.json). The initial independent check found **1.8%** maximum relative speed error for a closed chordal curve with uniform whole-parameter samples crossing control-point knots. Aligning table rows with segment boundaries fixed that failure without relaxing the 0.5% budget. Current frozen fixtures report maximum 2048-budget relative speed error **0.00021091** (0.0211%). This does not promise absolute constant speed for arbitrary paths, cusps or subdivision budgets.

## Performance evidence

Run `pnpm bench` from this package. [Initial results](evidence/performance-initial.json) failed the full-World budget: the 1000-follower p95 range was 31.8–93.9 ms, with concurrent builds and browser/graphics verification on the shared host. Those measurements remain negative evidence. The subsequent span implementation removes per-follower row materialization and scalar-validation arrays. [Earlier span results](evidence/performance-before-direction-validation.json) passed all six 1000-follower rounds (p95 0.944–7.895 ms). After the finite-direction correction, [shared-profiler results](evidence/performance-shared-profiler.json) failed five rounds; [serial results](evidence/performance-serial-contention.json) failed one round at 11.828 ms against the unchanged 8 ms ceiling. After the app build phase completed (with the Dawn roster continuing on the shared host), the [prior-source frozen wall-time run](evidence/performance-before-small-parent.json) passed all six 1000-follower rounds: p95 **1.364–4.832 ms**, with single-path preparation p95 **0.743 ms**. Complete cold frames (including path preparation) and all raw samples remain reported: the ten-path/1000-follower cold frame reached **65.280 ms**, and a warmed-frame maximum reached **45.574 ms** on this shared host. Passing p95 does not establish a worst-case frame bound. Different host loads and scheduling prohibit an improvement-factor claim. Retained heap/ArrayBuffer deltas are not allocation counts or a proof of zero allocation.

Three burst rounds have CPU p95 1.56–1.63 ms while two wall p95 exceed 8 ms; an external host-yield diagnostic reports wall p95 1.09–1.63 ms. Off-thread wall intervals can include scheduler/system waiting and GC work; this is an inference, not an identified operating-system root cause. Yielded timing and CPU timing do not replace the frozen wall-time acceptance benchmark.

## Allocation and lifecycle evidence

[`lifecycle.json`](evidence/lifecycle.json) records four fresh Worlds with 1000 followers, 64 changed-control/scale/table replacements each, removal and native detach. ArrayBuffer retention stabilizes at 145367 bytes after every detached round; final delta is -108500 bytes (frozen retention ceiling 1 MiB). A separate V8 HeapProfiler run (512-byte statistical sampling, collected allocations included) estimates 463–517 KB allocated per complete World frame. These are statistical allocation estimates, not object counts; path preparation and ECS frames remain allocation-bearing.

Scene entity-reference regression: the original Scene owner failed the forward-reference assertion; the repaired owner passes scalar, cyclic, array and mounted-carrier bindings across two independent instances while retaining the ChildOf/Children mirror. The Path package passes 33 tests, including small-parent/overflow regressions, desired-motion save/reload, 11 malformed Scene JSON cases rejected before storage coercion, and typed author controls projected by value. The prior Scene package run passed 97 tests. On baseline `2e2d9f1aa9`,96 passed while its unchanged100k performance case exceeded120 seconds during overlapping builds. On current main `112c12d8ce`,all97 tests and types pass. The unchanged failed case then passed in 33.83 seconds after the own build phase completed. The original owner accepted null/string/boolean controls, wrong fixed-array lengths and truncated/wrapped integer options; that red regression remains published with the repaired green route. A separate red reproducer caught finite up-magnitude × instance-scale overflow before normalization; up is now normalized as a direction before transformation. Ordinary saved-scene JSON roundtrip verifies retained distance and instance-local bindings.

A subsequent real-World regression found that a 0.0001-scale parent changed expected world Z=0.1 to Z=0.00001 through the general matrix inverse's documented small-determinant identity fallback. Path now performs affine point inversion directly and rejects unrepresentable Float32 local output before writing Transform. The red small-parent and overflow checks remain retained with their green rerun.
